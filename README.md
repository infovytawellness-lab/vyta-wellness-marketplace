# vyta-wellness-marketplace
Official repository for the Vyta Wellness Marketplace. This platform powers the end-to-end online shopping experience for health and wellness products, featuring seamless catalog browsing, user account management, shopping cart functionality, and secure order processing.


## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
